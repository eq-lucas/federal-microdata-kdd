# ✔️ 1️⃣ Efeitos marginais e probabilidades previstas

Você está certo:

É só **interpretar melhor o logit**.

* efeitos marginais
* probabilidades previstas

Então sim — é **apresentação dos resultados**, não novo modelo.

# ✔️ 2️⃣ Gráfico da interação

Também correto.

O modelo continua o mesmo:

[
\text{logit}(P(FIES=1))
]

Você só mostra graficamente:

* probabilidade vs nota
* linhas para níveis de renda

Então também é **forma de mostrar resultado**.

---

# ✔️ 3️⃣ Variáveis de controle

Aqui você também está certo.

Se você já rodou algo como:

[
logit(P(FIES=1)) =
Nota + Renda + Nota\times Renda + X
]

onde (X) são **70 controles**, então você já fez algo que muitos artigos fazem.

Isso já é um **modelo relativamente completo**.

---

# 📊 Então o que realmente deixa o artigo mais forte?

Se você já tem:

✔ interação
✔ renda contínua
✔ muitos controles

as melhorias geralmente vêm de **estrutura empírica**, não da regressão.

As três coisas que mais fortalecem seriam:

### 1️⃣ Comparar especificações

Exemplo de tabela:

| modelo | variáveis                |
| ------ | ------------------------ |
| 1      | nota                     |
| 2      | nota + renda             |
| 3      | nota + renda + interação |
| 4      | modelo completo          |

Isso mostra **robustez**.

---

### 2️⃣ Robustez

Testar:

* renda em log
* renda padronizada
* remover outliers

Se resultados continuam → modelo robusto.

---

### 3️⃣ Subamostras

Rodar o modelo para:

* apenas baixa renda
* apenas alta renda
* cursos diferentes

Isso mostra **heterogeneidade**.

---
